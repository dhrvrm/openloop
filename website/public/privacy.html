OpenLoopSource code

Your data stays understandable.

OpenLoop 1.0.3 runs transcription, correction, semantic memory, and storage on your Mac after the required models are downloaded. This release does not include a cloud transcription route.

What is stored

Typed captures, recordings kept for retry, transcripts, corrections, task state, semantic evidence, context settings, and action audit records are stored locally. The main vault is encrypted. Model files and retained source audio are separate local files.

Microphone and accessibility

Microphone access is requested when you start recording. Accessibility access is used only when you ask OpenLoop to insert text into another app. Audio import does not need microphone permission.

Network use

The first speech-model download needs a network connection. The current release does not silently route audio or transcripts to a hosted speech service.

Deletion and retention

You can delete individual transcripts and retained audio, apply a retention policy, or remove all OpenLoop data from the app. Removing all data also removes locally managed model and staging directories.

Community build

The downloadable 1.0.3 DMG is ad-hoc signed and is not Apple-notarized. Review the security policy and source before installing.

Questions

Open an issue in the public repository. Do not include private recordings, transcripts, keys, or account data.
